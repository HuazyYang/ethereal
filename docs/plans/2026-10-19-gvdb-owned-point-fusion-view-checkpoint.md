# M5 owned point-fusion and snapshot viewer checkpoint

Status: implemented and validated on Windows, 2026-10-19. The mega project remains in progress.

Samples `61efa21` fixes a batch-order root-growth defect exposed by the city scan. Sequential support activation could exhaust all configured levels while the complete batch fit a smaller root. FloatSupport now encloses the complete incoming half-open leaf bounds before activation, retaining the entire old root, existing IDs, leaf phase, flags and links. New ancestors are transactional; true extent overflow still rejects atomically. Default Legacy point topology keeps its prior root path. The concrete host helper adds no public interface IID/vtable change. CPU and public fixtures cover a compact two-point reproduction, shifted roots, inactive leaves, center-first leaf IDs, exact visit budgets, epoch behavior, old subtrees and rollback. The 34,083-point CPU city replay now produces 570 leaves with the original configuration (`build/m5-root-enclosure/{tests,city}.log`; `build/m5-point-api/*-batch-enclosure-tests.log`).

Samples `2996733` moves point-fusion onto public volume, PointSet, topology, gather and apron operators. Scanner/compaction equations and explicit CPU scan staging remain. Each topology/gather/apron preparation publishes in order; the sample retains the previous visible snapshot until all three succeed. A later failure requires reset and does not claim full-frame owner rollback. The application uses the public raw colored surface renderer and snapshot-only viewer metadata/overlays, with no duplicate volume/atlas/packed topology. Empty scans preserve publication identity, reset publishes a real empty owner, and old snapshots retain their bytes across subsequent scans and reset.

Samples `2f41413` adds raw snapshot voxel, perspective section, orthographic section and inset viewing. One retained publication supplies canonical buffers and metadata. Artifact validation checks both constant blocks and exact resource bindings; bounded insets preserve all pixels outside their rectangle. Empty publications produce background and positive-infinity depth. Existing scenes keep their rendering hooks and the previous raycast diagnostic. See the [view helper contract](../../ethereal-samples/src/gvdb_samples/samples/sample-utils/OwnedVolumeView.md).
