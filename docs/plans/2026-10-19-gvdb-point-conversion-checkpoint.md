# M5 raw point-stream conversion checkpoint

Status: implemented and validated on Windows, 2026-10-19. Public point factories and topology publication remain in progress under the [ownership plan](2026-10-18-gvdb-unified-volume-ownership.md).

Samples `a1fea31` adds validated raw stream descriptors and a Slang conversion entry. It supports one to four components, unsigned byte/ushort and IEEE float/double encodings, arbitrary byte offsets/strides, and interleaved attributes. Every destination word has one writer, preserving prefix/suffix/stride gaps. Unaligned source reads remain within validated padded allocations. Direct aliasing is rejected; external native aliasing is a caller contract.

Conversion uses explicit binary32 affine arithmetic. Double input rounds to binary32 and double output widens that result; this is not a double-precision transform. Identity preserves signed zero/subnormals, floating NaNs are canonicalized, and integer outputs clamp/truncate with nonfinite values mapped to zero. The retained converter only handled ushort3/float3 to tight float3; the additional representations and strides are extensions. [Detailed contract and evidence](../../ethereal-samples/docs/point-stream-conversion-plan.md).

Aggregate tests passed **4/4** in 2.67 seconds; graphics-only tests passed **3/3** in 2.50 seconds with CUDA Toolkit discovery disabled. Logs are `build/point-stream-{configure,build,tests}.log`, `build/point-stream-graphics-{configure,build,tests}.log`, and JUnit files in their respective build directories. Private native graphics validation is clean and CUDA Compute Sanitizer reports zero errors (`build/point-stream-private/`). Independent whole-buffer comparisons cover all 16 encoding pairs, odd offsets/strides, rounding ties, subnormals/signed zero, invalid ranges, guard bytes and associated position/velocity/color fields. An initial D3D11 signed-zero issue was corrected by keeping identity decode/widening in integer bit operations. No compiler or existing shader changes were needed.

The module validates descriptors and retains buffers; it does not record commands, authenticate external-buffer device ownership, or publish a volume generation. Public rebuild/accumulate, gather/scatter, normalized-ushort weighted color, voxelization and consumer integration remain open. Dense candidate adoption and the remaining voxel filters are separate uncommitted work at this checkpoint.
