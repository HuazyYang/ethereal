# M5 public points, reduction and custom renderer checkpoint

Status: implemented and validated on Windows, 2026-10-19. The mega project remains in progress.

Samples `f18a6b9` adds the public owned point-set/upload/topology interfaces without changing existing vtables. Preparation deep-copies strided CPU input; recording converts through the existing Slang kernel; explicit caller-completed readback creates an immutable point set from the actual GPU bytes. Position/velocity component counts and W are preserved, colors use byte storage units, and XYZ bounds use the converted finite values. Same-device point sets can be reused by another factory; upload tickets remain factory-specific. Full rebuild replaces the authoritative leaf set and changes its epoch. Accumulation preserves existing IDs and epochs. Signed support, minimum root level, inactive reactivation and empty inputs are explicit. Staging honors the owner's CPU pool limits before publication, and failed preparation leaves the owner unchanged. See the [point contract](../../ethereal-samples/src/gvdb_samples/gvdb/GVDBNvrhiPointApi.md).

Samples `4d0ee12` adds public retained-snapshot scalar reduction. It reads R32_FLOAT active interiors only, excludes every apron and unused slot, returns the exact included voxel count, and requires explicit caller submission/completion. GPU threads accumulate packed XY columns in float; CPU completion accumulates those partial sums in double before returning a float. Placement can therefore change rounding order. Old snapshots retain their original placement and result. The independent cancellation fixture returns 33.9375 before repacking and 34.9375 after repacking, while the retained original remains 33.9375; NaN/infinity poison in unused/apron storage is excluded. Active nonfinites follow the documented arithmetic. See the [reduction contract](../../ethereal-samples/src/gvdb_samples/gvdb/GVDBNvrhiReductionApi.md).

Samples `8727803` migrates render-kernel to public serializer/snapshot ownership and shares a small app-level VBX loader with render-to-file. Rendering binds the retained raw atlas/topology directly. A strict shader-artifact check validates thread shape, resource kinds/slots/spaces/counts/strides, constant-buffer layout and absence of entry uniforms before output allocation; an old structured-atlas artifact is explicitly rejected. The custom threshold, diffuse/reflected-sky equations and fixed miss color remain unchanged. The test-only structured renderer provides an exact image/depth comparison without becoming a production owner.

Samples `18c9396` updates the [retained CUDA inventory](../../ethereal-samples/docs/gvdb-cuda-entry-inventory.md). All 100 explicit kernels and replacement paths were checked again. Its categories describe accepted replacement roles, not a project completion percentage or permission to remove references.
